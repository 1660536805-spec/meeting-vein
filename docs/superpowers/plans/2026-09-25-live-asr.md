# Live Local ASR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show provisional transcription during recording and keep SenseVoiceSmall as final transcription.

**Architecture:** AudioWorklet captures PCM that the browser resamples to 16 kHz and sends in 480 ms frames through a WebSocket to a local streaming Paraformer runtime. Browser appends ordered partials; stopping preserves the existing final upload workflow.

**Tech Stack:** TypeScript, Vite, Vitest, FastAPI, FunASR, pytest.

**Spec:** `docs/superpowers/specs/2026-09-25-live-asr-design.md`

## Global Constraints

- Keep audio processing on the local machine.
- Preserve upload, retry, pause, and final board submission.
- Show measured latency without claiming the one-second target before a real test.

## Review Focus

- A second recording starts with an empty streaming cache and transcript.
- Paused audio must not enter the streaming model.
- A failed stream cannot block final SenseVoice transcription.
- Old stream messages cannot overwrite final text.
- WebSocket connections from unapproved origins are rejected.
