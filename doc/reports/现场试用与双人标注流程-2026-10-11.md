# 会脉现场试用与双人标注流程

本文用于真实试用和模型质量复测。现在没有真实参与者完成这份流程；勾选结果、截图和标注结论必须由实际参与者填写，不得把自动化测试或模型输出当作人工验收证据。

## 一、试用准备

- [ ] 在要演示的电脑运行完整模式：`bash scripts/start_local.sh`。不要使用 `AMO_SKIP_ASR=1`。
- [ ] 在 `http://127.0.0.1:5173/` 创建新会议，使用虚构内容，避免真实个人信息和机密。
- [ ] 检查状态面板：ASR 服务已就绪；模型状态明确显示真实模型提供方，不是 Mock。未配置有效模型时只做本地 ASR 流程测试，不记录为“真实 LLM 试用”。
- [ ] 用户自行授予浏览器麦克风权限，并确认输入设备与音量。
- [ ] 记录电脑型号、操作系统、浏览器、ASR/LLM 模型名、代码提交号、网络情况和试用者代号。

## 二、约 10 分钟会议脚本

以下内容是可直接朗读的虚构样例。每项之间停顿 2–3 秒，便于检查分段与发言人归属。

1. 主持人：“今天讨论远程办公试点，先从一个小团队开始。”
2. 参与者甲：“我支持试点，远程办公能减少通勤，也能提高专注度。”
3. 参与者乙：“我反对立即扩大范围，跨团队协作和数据安全还没有验证。”
4. 主持人：“大家同意先试点两周，收集协作效率和安全问题后再决定是否扩大。”
5. 主持人：“林同学在周五前整理试点指标，王同学在下周一前汇总安全检查项。”

检查并记录：

- [ ] 录音过程中看得到正在识别的文本；停止录音后，实时片段按原顺序逐段进入待审核区，完整转写仅作遗漏核对参考。
- [ ] 逐段修订一个转写词，并给不同片段手动填写甲、乙发言人；刷新页面后继续核对，提交后检查原话和人工指定的发言人都已保存。
- [ ] 发言人归属目前是逐段人工填写；系统不做自动说话人识别。未填写时保留“本地发言人”，不得把它作为识别结果。
- [ ] 观点和结论卡能回到原话与发言人；结论在人工确认前显示待确认。
- [ ] 检查甲、乙的观点是否被识别为矛盾候选；若两项挂在不同议题下，先核对两侧议题归属和原话。候选只有在试用者确认后才应形成反对边。
- [ ] 若出现重复候选，分别查看“保留左项”和“保留右项”的影响预览；仅在确认迁移的原话、关系和子节点正确后合并，并验证可撤销。
- [ ] 两条行动均有正确负责人和截止日；下载 `.ics` 后导入本机日历，检查标题、负责人、截止时间和提前一天/到期提醒。逾期订阅应从下一个可用的本地 09:00 开始每日提醒，不应补出截止日以来的历史重复事件。在历史页订阅“全部会议行动项”，确认事件带有会议名；日历客户端按自身策略刷新，本机服务需保持运行。
- [ ] 若已配置 `AMO_TASK_WEBHOOK_URL`，点击“同步到任务工具”，检查稳定任务编号、负责人、期限、状态和版本；重复点击不应创建重复任务。未配置真实接收端时，记录为未验收，不要用自动化测试替代。
- [ ] 结束会议，导出 Markdown 或 HTML 纪要，确认未确认结论、分歧和待办状态没有被写成已确认结果。

## 三、跨会议复盘

1. [ ] 新建第二场会议，议题改写为“远程协作效率评估”。
2. [ ] 在“历史”页打开第二场会议，刷新“延续议题建议”；再用旧会议名、议题名和只出现在旧会原话里的证据词搜索默认列表之外的候选。对“搜索命中旧会议资料”的结果，填入旧议题后手动选择本会议议题并核对两边原话。
3. [ ] 检查系统是否利用第一场会议下的观点、决议、行动项内容找到候选；候选需人工确认，不应自动建立关联。
4. [ ] 对照候选卡上的上次与本次原话摘录；输入不带空格的证据词检索，例如“华东区”，检查是否能找到默认列表外的旧会议。
5. [ ] 将正确候选填入关联表单，填写实际关联人和原因后提交。
6. [ ] 检查时间线是否展示上次人工决议、这次证据和上次未完成行动；确认未选中的候选没有被自动关联。

## 四、双人独立标注和质量复测

1. 标注负责人从 `backend/tests/annotations/scheme-200-labeling-queue.csv` 和 `task-200-labeling-queue.csv` 复制两份独立文件，分别交给标注者 A、B。两人不得查看对方结果、模型预测或旧错误切片。
2. 按 `backend/tests/annotations/labeling-protocol.md` 标出类型、关系目标、重复簇与备注。特别区分“辩论立场”与“会议已达成的结论”。
3. 仲裁者逐项记录分歧理由，保留两份原始文件与仲裁版。冻结后记录日期、标注者代号和 SHA-256；先检查各类别与关系正例数量是否足以评分。
4. 仅在模型额度和数据授权允许时生成新的真实 LLM 预测；保存模型名、提示词版本、运行时间、失败行和预测文件。评估脚本可离线评分，不能把 Mock 结果写成真实模型指标。
5. 比较类型 macro-F1、每类 precision/recall/F1、oppose precision/recall、重复 pairwise F1、目标归属准确率、缺失预测率，并给出样本数。新金标与旧口径不同的指标应分开报告。
